## Q1. Create a singly LL and insert N nodes

> Create a singly linked list, given an input n, get input for n nodes, create the list and display the list

---

### Java code
```java
import java.util.*;

// LinkedList

class Node{
  int data;
  Node next;
  Node(int data){
    this.data=data;
  }
}
class LinkedList{
    Node head;
    Node temp;
    void insert(int data){
        if(head==null){
          head=new Node(data);
          // without using constructor means
          // head.data=data;
          temp=head;
        }else{
          Node newNode=new Node(data);
          temp.next=newNode;
          temp=newNode;
        }
    }
    void display(){
      temp=head;
      while(temp!=null){
        if(temp.next!=null) System.out.print(temp.data+"->");
        else{
          System.out.println(temp.data+"->null");
        }
        temp=temp.next;
      }
    }
}
public class Main {
    public static void main(String[] args) {
      Scanner sc=new Scanner(System.in);
      LinkedList ll=new LinkedList(); // create an obj for LL
      for(int i=0;i<n;i++){
        ll.insert(sc.nextInt());
      }
      ll.display();
    }
}

```
