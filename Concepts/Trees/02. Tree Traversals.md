# 🌳 Tree Traversals (DFS)

Depth First Search (DFS) traverses a tree by exploring one branch completely before moving to the next. The three recursive DFS traversals differ only in the order in which the **Root**, **Left**, and **Right** nodes are visited.

---

# 🌿 1. Preorder Traversal

**Order:** 👉 Root → Left → Right

![Preorder Traversal](https://media.geeksforgeeks.org/wp-content/uploads/20251001114610496243/preorder_traversal_of_binary_tree_12.webp)

```java
public void preorder(TreeNode root) {
    if(root==null)return;
    System.out.print(root.val+" ");
    preorder(root.left);
    preorder(root.right);
}
```

### 💡 Used In

- Tree copying
- Tree serialization
- Constructing trees from traversals

---

# 🌿 2. Inorder Traversal

**Order:** 👉 Left → Root → Right

![Inorder Traversal](https://media.geeksforgeeks.org/wp-content/uploads/20251003115347094274/inorder_traversal_of_binary_tree_12.webp)

```java
public void inorder(TreeNode root) {
    if(root==null)return;

    inorder(root.left);
    System.out.print(root.val+" ");
    inorder(root.right);
}
```

### ⭐ Key Observation

For a **Binary Search Tree (BST)**,

- Inorder traversal always visits the nodes in **sorted order**.

---

# 🌿 3. Postorder Traversal

**Order:** 👉 Left → Right → Root

![Postorder Traversal](https://media.geeksforgeeks.org/wp-content/uploads/20250327114308546515/Postorder-Traversal-of-Binary-Tree-6.webp)

```java
public void postorder(TreeNode root) {
    if(root==null)return;
    postorder(root.left);
    postorder(root.right);
    System.out.print(root.val+" ");
}
```

### 💡 Used In

- Tree deletion
- Subtree calculations
- Height and depth problems
- Dynamic Programming on Trees

---

# 📌 Quick Summary

| Traversal | Order | Common Uses |
|-----------|-------|-------------|
| 🌿 **Preorder** | Root → Left → Right | Tree copying, Serialization, Tree construction |
| 🌿 **Inorder** | Left → Root → Right | Sorted traversal of BST |
| 🌿 **Postorder** | Left → Right → Root | Deletion, Height, Subtree calculations, DP on Trees |
