A binary tree node usually looks like this in Java:

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode(int val) {
        this.val = val;
    }
}
```

Each node consists of:

- **Value (`val`)** – Stores the data.
- **Left Child (`left`)** – Points to the left subtree.
- **Right Child (`right`)** – Points to the right subtree.

---

## Binary Tree Structure

A binary tree is a hierarchical data structure where each node has at most **two children**.

Example:

```
        1
       / \
      2   3
     / \
    4   5
```

Here:

- `1` is the **Root**
- `2` and `3` are children of `1`
- `4` and `5` are children of `2`
- `3`, `4`, and `5` are leaf nodes

---

## Terminologies

| Term | Meaning |
|------|---------|
| Root | First node of the tree |
| Parent | Node having child nodes |
| Child | Node connected below a parent |
| Leaf | Node with no children |
| Subtree | Tree formed from any node and its descendants |
| Height | Number of edges in the longest path to a leaf |
| Depth | Distance from the root to a node |
