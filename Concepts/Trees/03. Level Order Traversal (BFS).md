# 🌳 Level Order Traversal (BFS)

Level Order Traversal visits the tree **level by level**, starting from the root. It follows the **Breadth First Search (BFS)** approach and uses a **Queue** to process nodes in the order they appear.

---

## 🌿 Traversal Order

👉 Level by Level (Top → Bottom)

## 💻 Java Implementation

```java
import java.util.*;

public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> ans = new ArrayList<>();

    if(root == null) return ans;

    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);

    while(!q.isEmpty()) {

        int size = q.size();
        List<Integer> level = new ArrayList<>();

        for(int i = 0; i < size; i++) {

            TreeNode node = q.poll();

            level.add(node.val);

            if(node.left != null)
                q.offer(node.left);

            if(node.right != null)
                q.offer(node.right);
        }

        ans.add(level);
    }

    return ans;
}
```

---

## ⭐ Key Observation

- A **Queue** ensures nodes are processed in **First In, First Out (FIFO)** order.
- At the beginning of each iteration, `size = q.size()` gives the **number of nodes in the current level**.
- The `for` loop processes exactly one level before moving to the next.

---

## 💡 Algorithm

1. Create an empty queue.
2. Insert the root node into the queue.
3. While the queue is not empty:
   - Find the current queue size.
   - Process exactly `size` nodes.
   - Store their values in a list.
   - Push their left and right children into the queue.
4. Add the current level to the answer.
5. Repeat until the queue becomes empty.

## ⏱️ Complexity

| Operation | Complexity |
|-----------|-----------:|
| Time | **O(n)** |
| Space | **O(n)** |

**Reason:**

- Every node is visited exactly once.
- In the worst case, the queue may contain all nodes of the largest level.

---

## 📌 Key Takeaways

- ✅ Uses **Breadth First Search (BFS)**.
- ✅ Implemented using a **Queue**.
- ✅ Processes nodes **level by level**.
- ✅ `q.size()` determines the number of nodes in the current level.
- ✅ Foundation for many tree-based BFS problems.
