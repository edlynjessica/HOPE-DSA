# 🌳 Binary Tree Concepts

These are some of the most important concepts used in Binary Tree problems. Most interview questions are built around these recursion patterns.

---

# 🌿 1. Height / Depth of a Tree

The **height (or maximum depth)** of a tree is the number of nodes in the longest path from the root to a leaf node.

```java
public int maxDepth(TreeNode root) {

    if(root == null)
        return 0;

    return 1 + Math.max(maxDepth(root.left),
                        maxDepth(root.right));
}
```

### ⭐ Key Observation

The height of a node depends on the maximum height of its left and right subtrees.

```
Height = 1 + max(leftHeight, rightHeight)
```

---

# 🌿 2. Balanced Binary Tree

A binary tree is said to be **balanced** if the height difference between the left and right subtrees of every node is at most **1**.

```java
public boolean isBalanced(TreeNode root) {
    return height(root) != -1;
}

public int height(TreeNode root) {

    if(root == null)
        return 0;

    int left = height(root.left);
    int right = height(root.right);

    if(left == -1 || right == -1)
        return -1;

    if(Math.abs(left - right) > 1)
        return -1;

    return 1 + Math.max(left, right);
}
```

### ⭐ Key Observation

Instead of checking every subtree separately, return **-1** whenever an unbalanced subtree is found.

This allows the recursion to stop early.

# 🌿 3. Diameter of a Binary Tree

The **diameter** of a binary tree is the **longest path between any two nodes**.

The path **may or may not** pass through the root.

```java
int diameter = 0;

public int diameterOfBinaryTree(TreeNode root) {

    height(root);
    return diameter;
}

public int height(TreeNode root) {

    if(root == null)
        return 0;

    int left = height(root.left);
    int right = height(root.right);

    diameter = Math.max(diameter, left + right);

    return 1 + Math.max(left, right);
}
```

### ⭐ Key Observation

At every node,

```
Diameter = Left Height + Right Height
```

The maximum of all such values is the answer.

# 📌 Key Takeaways

- ✅ Height is computed using recursion.
- ✅ Balanced Tree uses **height + early termination (-1)**.
- ✅ Diameter is calculated while computing heights.
- ✅ Most Binary Tree problems follow a recursive DFS approach.
