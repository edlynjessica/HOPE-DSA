# 🌳 Trees

Trees are hierarchical data structures where each node contains a value and references to its child nodes. They are one of the most important topics in Data Structures and Algorithms, frequently appearing in coding interviews due to their recursive nature and wide range of applications.

This section covers the fundamental concepts of **Binary Trees** and **Binary Search Trees (BSTs)**, along with common traversal techniques, recursion patterns, and frequently used algorithms.

# 💡 Problem-Solving Strategy

When solving a tree problem, ask yourself:

- Is this a **DFS** or **BFS** problem?
- What should my recursive function return?
- Can the answer be built using the left and right subtrees?
- Do I need a global variable to maintain the final answer?
