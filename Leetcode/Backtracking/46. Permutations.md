## 📖 Problem Statement

Given an array `nums` of **distinct integers**, return **all possible permutations**.

You may return the answer in any order.

---

# 💡 Observation

A permutation is simply an arrangement of all the given numbers.

At every step,

we choose one unused number and place it in the current permutation.

Once a number is chosen, it cannot be used again until we backtrack.

---

# 🧠 Backtracking Thinking

## What does the question ask?

Generate **all possible permutations** of the given array.

---

## State

During recursion, maintain:

```
curr
```

Current permutation being built.

```
used[]
```

Keeps track of whether each element has already been used.

---

## Choice

For every recursive call,

iterate through all numbers.

If a number has **not been used**,

- Choose it.
- Add it to the current permutation.
- Recurse.
- Undo the choice.

---

## Base Case

When

```
curr.size() == nums.length
```

a complete permutation has been formed.

Store a copy of it in the answer list.

---

# ✅ Approach : Backtracking

### Idea

Start with an empty permutation.

At every level,

try placing every unused number.

After exploring that choice,

undo it so the next number can be tried.

This guarantees that every possible permutation is generated exactly once.

---

### Time Complexity

```
O(n × n!)
```

There are

```
n!
```

possible permutations,

and each permutation requires

```
O(n)
```

time to copy into the answer list.

---

### Space Complexity

```
O(n)
```

Recursion Stack

+

```
O(n)
```

Used Array

(The answer list is not included in auxiliary space.)

---

### Code

```java
class Solution {
    static List<List<Integer>> ans;
    static boolean[] used;
    public List<List<Integer>> permute(int[] nums) {
        ans=new ArrayList<>();
        used=new boolean[nums.length];
        backtrack(new ArrayList<>(),nums); // initially start with empty []
        return ans;
    }
    static void backtrack(List<Integer> curr, int[] nums){
        // base case
        if(curr.size()==nums.length){
            ans.add(new ArrayList<>(curr)); // store the copy
            return;
        }
        // iterate through nums
        for(int i=0;i<nums.length;i++){
            if(used[i]) continue; // if nums[i] already used, skip it
            // else.. choose it
            used[i]=true; // choose
            curr.add(nums[i]); // add
            backtrack(curr,nums); // recurse
            curr.remove(curr.size()-1); // undo
            used[i]=false; // unchoose
        }
    }
}
```

# 🎯 Key Takeaways

- Permutations is a classic **Backtracking** problem.
- At every recursive call, try choosing every unused element.
- Maintain:
  - `curr` → current permutation.
  - `used[]` → tracks which elements have already been chosen.
- Follow the backtracking pattern:
  - **Choose**
  - **Explore**
  - **Undo**
- Store a **copy** of the current permutation:

```
new ArrayList<>(curr)
```

Otherwise, every answer would point to the same list.
- Since all numbers are distinct, each permutation is generated exactly once.
