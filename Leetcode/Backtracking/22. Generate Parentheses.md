# 22. Generate Parentheses

## 📖 Problem Statement

Given `n` pairs of parentheses, generate **all possible well-formed combinations** of parentheses.

Return the answer in any order.

---

# 💡 Observation

At every step, there are only **two choices**:

- Add an opening parenthesis `'('`
- Add a closing parenthesis `')'`

However, we cannot generate every possible string because many combinations would be invalid.

Instead, we only continue building strings that can still become **well-formed parentheses**.

---

# 🧠 Backtracking Thinking

## What does the question ask?

Generate **all valid combinations** of `n` pairs of parentheses.

---

## State

During recursion, keep track of:

```
s
```

Current parentheses string being built.

```
open
```

Number of opening parentheses used.

```
close
```

Number of closing parentheses used.

---

## Choices

### Choice 1 : Add '('

We can add an opening parenthesis only if

```
open < n
```

---

### Choice 2 : Add ')'

We can add a closing parenthesis only if

```
close < open
```

This guarantees that the string never becomes invalid.

---

## Base Case

When the string length becomes

```
2 × n
```

a complete valid combination has been formed.

Add it to the answer list.

---

# ✅ Approach : Backtracking

### Idea

Start with an empty string.

At every recursive call,

- Try adding `'('` if possible.
- Try adding `')'` if it keeps the string valid.

Continue until a complete valid string is formed.

Since invalid states are never explored, backtracking efficiently generates only valid combinations.

---

### Time Complexity

```
O(4ⁿ / √n)
```

The number of valid parentheses combinations is the **nᵗʰ Catalan Number**, which grows approximately as:

```
4ⁿ / (n^(3/2))
```

Each valid string has length `2n`.

---

### Space Complexity

```
O(n)
```

Recursion Stack

(The answer list is not included in auxiliary space.)

---

### Code

```java
class Solution {
    static List<String> ans;
    public List<String> generateParenthesis(int n) {
        ans=new ArrayList<>();
        backtrack("",0,0,n);
        return ans;
    }
    static void backtrack(String s,int open,int close, int n){
        // base case -> add the well formed
        if(s.length()==2*n){
            ans.add(s);
            return;
        }
        // choice 1 , add "("
        if(open<n){
            open++; // add
            backtrack(s+"(",open,close,n); // recurse, if valid, gets added to ans
            open--; // undo 
        }
        // choice 2 , add ")"
        if(open>close){
            close++; // add 
            backtrack(s+")",open,close,n); // recurse, if valid, gets added to ans
            close--; // undo
        }
    }
}
```

---

# 🌳 Recursion Tree (n = 2)

```
                      ""
                   /     
                 "("
               /     \
            "(("     "()"
              |        |
           "(()"    "()("
              |        |
          "(())"   "()()"
```

Generated Answer:

```
["(())", "()()"]
```

---

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Backtracking | O(4ⁿ / √n) | O(n) |

# 🎯 Key Takeaways

- Generate Parentheses is a classic **Backtracking** problem.
- At every step, there are two possible choices:
  - Add `'('`
  - Add `')'`
- Only valid states are explored.
- An opening parenthesis can be added only if:

```
open < n
```

- A closing parenthesis can be added only if:

```
close < open
```

- Once the string length becomes:

```
2 × n
```

a valid combination has been generated.
- Strings are immutable in Java, so `s + "("` creates a new string. There is no need to "undo" changes after the recursive call.
- Unlike Dynamic Programming, backtracking explores all valid possibilities without storing subproblem results.
