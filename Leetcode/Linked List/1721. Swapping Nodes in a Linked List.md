## 📖 Problem Statement

Given the head of a singly linked list and an integer `k`, swap the **values** of:

- The `k`th node from the beginning.
- The `k`th node from the end.

The list is **1-indexed**.

The goal is to perform the swap without creating extra space.

---

## 💡 Key Idea

We need to find two nodes:
We can find both using two pointers.

Instead of:

Find length

→ calculate position from end

→ traverse again

we can use the **fast and slow pointer** technique.

---

## 🧠 Two Pointer Approach

#### Step 1: Find the kth node from the beginning

Move first exactly k - 1 times.
```
head
 ↓
1 → 2 → 3 → 4 → 5
```
k = 2
```
first
 ↓
 2
```
So first points to the kth node from the beginning.

#### Step 2: Create a gap of k - 1

Now set:
```
second = head;
fast = first;
```
Move fast and second together until fast reaches the last node.

Because first is already at position k, maintaining this gap makes second land on the kth node from the end.

---

### 🔍 Example

List:
```
1 → 2 → 3 → 4 → 5
```
k = 2

First find the 2nd node:
```
1 → 2 → 3 → 4 → 5
    ↑
  first
```
Now:

second = head

Move both pointers together:
```
second
  ↓
1 → 2 → 3 → 4 → 5
        ↑
       first
```
Continue until first reaches the last node:
```
1 → 2 → 3 → 4 → 5
    ↑           ↑
  second       first
```
Therefore:
```
first  = 2nd node from beginning
second = 2nd node from end
```
Swap their values:
```
1 → 4 → 3 → 2 → 5
```

---

## 🔄 Code
``` java
class Solution {

    public ListNode swapNodes(ListNode head, int k) {

        // Find kth node from the beginning
        ListNode first = head;

        for(int i = 1; i < k; i++){
            first = first.next;
        }

        // second will eventually point to
        // kth node from the end
        ListNode second = head;
        ListNode fast = first;

        while(fast.next != null){
            fast = fast.next;
            second = second.next;
        }

        // Swap values
        int temp = first.val;
        first.val = second.val;
        second.val = temp;

        return head;
    }
}
```

--- 

## 🧠 Why Does This Work?

Suppose the list has n nodes.

After moving first to the kth node:
```
first = position k
```
second starts at position 1.

Then both move together until first reaches the last node.

The number of positions between them remains:
```
k - 1
```
Therefore, when:

first = position n

second will be at:
```
n - (k - 1) = n - k + 1
```
which is exactly the **kth node from the end.**

---

## 📊 Complexity

| Complexity            | Value      |
| --------------------- | ---------: |
| Time	                | `O(n)`     |
| Space	                | `O(1)`     |

We only use a few pointers, so the algorithm uses constant extra space.

---

## 🎯 Important Point

We are swapping the values, not the actual nodes.
``` java
int temp = first.val;
first.val = second.val;
second.val = temp;
```
This is much simpler than physically rearranging the nodes.

---

## ⭐ Pattern

This is a useful Two Pointer / Fast & Slow Pointer pattern:
```
Find kth node from beginning
          ↓
Create a fixed gap
          ↓
Move both pointers together
          ↓
Second pointer reaches kth node from end
          ↓
Swap values
```

---

## Key takeaway

When you need to find a node from the end of a singly linked list without using extra space, think about maintaining a fixed gap between two pointers.

1. kth node from the beginning
2. kth node from the end
