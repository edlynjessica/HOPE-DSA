## 📖 Problem Statement

Given an integer `n`, return the **least number of perfect square numbers** whose sum equals `n`.

A perfect square is an integer that is the square of another integer.

Examples:

```
1, 4, 9, 16, 25, ...
```

---

# 💡 Observation

A number can be formed using different perfect squares.

For every perfect square, we decide whether using it reduces the minimum number of squares required.

This is very similar to the **Coin Change** problem, where the perfect squares act as the available coins.

Since every state depends on previously computed smaller states, this is a **1D Dynamic Programming** problem.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **minimum number of perfect squares** whose sum equals `n`.

---

## What is the subproblem?

Let

```
dp[i]
```

represent the **minimum number of perfect squares required to make the value `i`**.

---

## Recurrence Relation

For every perfect square,

```
sq = i × i
```

update every possible value.

```
dp[j] = min(dp[j], dp[j-sq] + 1)
```

The `+1` represents using the current perfect square.

---

## Base Case

```
dp[0] = 0
```

Zero perfect squares are needed to make the value `0`.

---

## Initialization

Initially,

assume every value requires an infinite number of perfect squares.

```
dp[i] = n + 1
```

This acts as **INF**.

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Generate every perfect square less than or equal to `n`.

For each perfect square,

update all values that can be formed using that square.

Finally,

`dp[n]` stores the minimum number of perfect squares required.

---

### Time Complexity

```
O(n√n)
```

There are approximately
```
√n
```
perfect squares,
and for each one, we iterate through at most

```
n
```
states.

---

### Space Complexity

```
O(n)
```

---

### Code

```java
class Solution {
    public int numSquares(int n) {
        // Tabulation

        int[] dp=new int[n+1];

        Arrays.fill(dp,n+1);

        dp[0]=0;

        for(int i=1;i*i<=n;i++){

            int sq=i*i;

            for(int j=sq;j<=n;j++){
                dp[j]=Math.min(dp[j], dp[j-sq]+1);
            }
        }

        return dp[n];
    }
}
```

---

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Tabulation | O(n√n) | O(n) |

# 🎯 Key Takeaways

- Perfect Squares is a classic **1D Dynamic Programming** problem.
- Define the DP state as:

```
dp[i]
```

= Minimum number of perfect squares required to make the value `i`.

- The recurrence relation is:

```
dp[j] = min(dp[j], dp[j-sq] + 1)
```

- Initialize every state with **INF (`n + 1`)**.
- Set the base case:

```
dp[0] = 0
```

- This problem follows the same DP pattern as **Coin Change**, where the perfect squares behave like the available coin denominations.
- Build the answer iteratively until reaching `dp[n]`.
