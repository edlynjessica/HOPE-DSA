# 746. Min Cost Climbing Stairs

**Difficulty:** Easy  
**Topic:** Dynamic Programming → 1D DP

---

## Key Observation

To reach the current stair, you can come from:

- The previous stair `(i - 1)`
- Two stairs before `(i - 2)`

Choose the path with the **minimum cost**.

Hence,

```
minCost(i) = min(minCost(i-1), minCost(i-2)) + cost[i]
```

The answer is:

```
min(minCost[n-2], minCost[n-1])
```

---

# Approach: Tabulation

### Java

```java
class Solution {
    // tabulation approach
    public int minCostClimbingStairs(int[] cost) {
        int n=cost.length;
        int[] minCost=new int[n];
        minCost[0]=cost[0];
        minCost[1]=cost[1];
        for(int i=2;i<n;i++){
            minCost[i]=Math.min(minCost[i-1],minCost[i-2]) + cost[i];
        }
        return Math.min(minCost[n-2],minCost[n-1]);
    }
}
```

### Time Complexity

**O(n)**

### Space Complexity

**O(n)**

---

## Key Takeaways

- Classic **1D Dynamic Programming** problem.
- Similar to **Climbing Stairs**, but stores the **minimum cost** instead of the number of ways.
- At each stair, choose the cheaper path from the previous two stairs.
- The final answer is the minimum cost of reaching either of the last two stairs.
