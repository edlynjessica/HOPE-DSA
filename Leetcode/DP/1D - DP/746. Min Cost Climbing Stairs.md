# 746. Min Cost Climbing Stairs

**Difficulty:** Easy  
**Topic:** Dynamic Programming → 1D DP

---

## Key Observation

To reach the current stair, you can come from:

- The previous stair `(i - 1)`
- Two stairs before `(i - 2)`

Choose the path with the **minimum cost**.

Hence,

```
minCost(i) = min(minCost(i-1), minCost(i-2)) + cost[i]
```

The answer is:

```
min(minCost[n-2], minCost[n-1])
```

---

# Approach 1: Recursion (Brute Force)

### Java

```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n=cost.length;
        return Math.min(helper(cost, n-1), helper(cost, n-2));
    }
    static int helper(int[] cost, int i) {
        if(i==0) return cost[0];
        if(i==1) return cost[1];
        return cost[i] + Math.min(helper(cost, i-1), helper(cost, i-2));
    }
}
```

### Time Complexity

**O(2ⁿ)**

### Space Complexity

**O(n)**

---

# Approach 2: Memoization

### Java

```java
class Solution {
    static int[] dp;
    public int minCostClimbingStairs(int[] cost) {
        int n=cost.length;
        dp=new int[n];
        Arrays.fill(dp, -1);
        return Math.min(helper(cost, n-1), helper(cost,n-2));
    }

    private int helper(int[] cost, int i) {
        if(i==0) return cost[0];
        if(i==1) return cost[1];
        if(dp[i]!=-1) return dp[i];
        dp[i]=cost[i] + Math.min(helper(cost, i-1),
                                   helper(cost, i-2));

        return dp[i];
    }
}
```

### Time Complexity

**O(n)**

### Space Complexity

**O(n)**

# Approach 3: Tabulation

### Java

```java
class Solution {
    // tabulation approach
    public int minCostClimbingStairs(int[] cost) {
        int n=cost.length;
        int[] minCost=new int[n];
        minCost[0]=cost[0];
        minCost[1]=cost[1];
        for(int i=2;i<n;i++){
            minCost[i]=Math.min(minCost[i-1],minCost[i-2]) + cost[i];
        }
        return Math.min(minCost[n-2],minCost[n-1]);
    }
}
```

### Time Complexity

**O(n)**

### Space Complexity

**O(n)**

---

## Key Takeaways

- Classic **1D Dynamic Programming** problem.
- Similar to **Climbing Stairs**, but stores the **minimum cost** instead of the number of ways.
- Can be solved using **Recursion**, **Memoization**, or **Tabulation**.
- At each stair, choose the cheaper path from the previous two stairs.
- The final answer is the minimum cost of reaching either of the last two stairs.
