# 70. Climbing Stairs

**Difficulty:** Easy  
**Topic:** Dynamic Programming → 1D DP

---

## Key Observation

To reach the **nth** stair, there are only two possibilities:

- Climb **1 step** from `(n - 1)`
- Climb **2 steps** from `(n - 2)`

Hence,

```
ways(n) = ways(n - 1) + ways(n - 2)
```

---

# Approach 1: Tabulation

### Java

```java
class Solution {
    // tabulation dp approach
    public int climbStairs(int n) {
        if(n<=3) return n;
        int[] dp=new int[n+1];
        dp[0]=1; // to reach 1st step , 1 way
        dp[1]=2; // to reach 2nd step, 2 ways
        dp[2]=3; // to reach 3rd step, 3 ways
        for(int i=3;i<n;i++){
            dp[i]=dp[i-1]+dp[i-2];
        }
        return dp[n-1];
    }
}
```

### Time Complexity

**O(n)**

### Space Complexity

**O(n)**

---

# Approach 2: Memoization

### Java

```java
class Solution {
    // memoization dp approach
    static int[] dp;
    public int climbStairs(int n) {
        dp=new int[n+1];
        Arrays.fill(dp,-1);
        return memo(n);
    }
    public int memo(int n){
        if(n==1 || n==2) return n;
        if(dp[n]!=-1){
            return dp[n];
        }
        dp[n]=memo(n-1)+memo(n-2);
        return dp[n];
    }
}
```

### Time Complexity

**O(n)**

### Space Complexity

**O(n)**

*(Memoization array + recursion stack)*

---

## Key Takeaways

- Classic **1D Dynamic Programming** problem.
- Can be solved using **Tabulation** or **Memoization**.
- Both approaches follow the same recurrence relation:

```
ways(n) = ways(n - 1) + ways(n - 2)
```
