## 📖 Problem Statement

You are a professional robber planning to rob houses along a street. Each house contains a certain amount of money.

The only constraint is that **adjacent houses cannot be robbed**, otherwise the police will be alerted.

Given an integer array `nums`, where `nums[i]` represents the amount of money in the `iᵗʰ` house, return the **maximum amount of money** that can be robbed without robbing two adjacent houses.

---

# 💡 Observation

For every house, there are only **two choices**:

- **Rob the current house** and skip the previous one.
- **Skip the current house**.

At every step, we choose the option that gives the **maximum profit**.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **maximum amount of money** that can be robbed without robbing adjacent houses.

---

## What is the subproblem?

Let

```
dp[i]
```

represent the **maximum amount of money that can be robbed from houses `0` to `i`.**

---

## Recurrence Relation

For every house, there are two choices.

### Skip the current house

```
dp[i-1]
```

### Rob the current house

```
dp[i-2] + nums[i]
```

Choose the maximum.

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

---

## Base Cases

```
dp[0] = nums[0]

dp[1] = max(nums[0], nums[1])
```

---

# ✅ Approach 1 : Basic Recursion

### Idea

For every house, there are only two choices.

- **Rob the current house** and move to house `i+2`.
- **Skip the current house** and move to house `i+1`.

Recursively calculate both possibilities and return the maximum.

### Time Complexity

```
O(2ⁿ)
```

### Space Complexity

```
O(n)
```

(Recursion Stack)

### Code

```java
class Solution {
    public int rob(int[] nums) {
        return helper(nums,0);
    }
    static int helper(int[] nums,int i){
        if(i>=nums.length) return 0;
        int rob=nums[i]+helper(nums,i+2);
        int skip=helper(nums,i+1);
        return Math.max(rob,skip);
    }
}
```

---

# ✅ Approach 2 : Memoization (Top-Down DP)

### Idea

Solve the problem recursively while storing the answer for each house.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(n)
```

DP Array + Recursion Stack

```
O(n)
```

### Code

```java
class Solution {
    static int[] dp;
    public int rob(int[] nums) {
        // dp memoization approach 
        int n=nums.length;
        if(n==1) return nums[0];
        dp=new int[n];
        Arrays.fill(dp,-1);
        // initialise base case dp values
        dp[0]=nums[0];
        dp[1]=Math.max(nums[0],nums[1]);
        return memoize(nums,n-1); // max amt robbed after reaching the last house
    }
    static int memoize(int[] nums,int i){
        if(dp[i]!=-1) return dp[i];
        dp[i]=Math.max(memoize(nums,i-1),memoize(nums,i-2)+nums[i]);
        return dp[i];
    }

}
```

# ✅ Approach 3 : Tabulation (Bottom-Up DP)

### Idea

Instead of solving recursively,

build the DP array from left to right.

Each state is calculated using the answers of the previous two states.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(n)
```

### Code

```java
class Solution { 
    public int rob(int[] nums) {
        // dp tabulation approach

        int n=nums.length;
        int[] dp=new int[n];
        dp[0]=nums[0];
        dp[1]=Math.max(nums[1],nums[0]);
        for(int i=2;i<n;i++){
            dp[i]=Math.max(dp[i-1],dp[i-2]+nums[i]);
        }
        return dp[n-1];
    }
}
```

# ✅ Approach 4 : Space Optimized DP

### Observation

Notice that

```
dp[i]
```

depends only on

```
dp[i-1]

and

dp[i-2]
```

Therefore, instead of storing the entire DP array, we only keep track of the previous two answers.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(1)
```

### Code

```java
class Solution {
    // DP Tabulation Space Optimized Version
    public int rob(int[] nums) {
        int n=nums.length;
        if(n==1) return nums[0];

        // base cases
        int prev2=nums[0]; // first house
        int prev1=Math.max(nums[0],nums[1]); // second house
        int prev=0;
        for(int i=2;i<n;i++){
            prev=Math.max(prev1,prev2+nums[i]);
            prev2=prev1;
            prev1=prev;
        }
        return prev1;
    }
}
```

| Basic Recursion | O(2ⁿ) | O(n) |
| Memoization | O(n) | O(n) + O(n) |
| Tabulation | O(n) | O(n) |
| Space Optimized | O(n) | O(1) |

# 🎯 Key Takeaways

- House Robber is a classic **1D Dynamic Programming** problem.
- At every house, there are only two choices:
  - **Rob the current house**
  - **Skip the current house**
- The recurrence relation is:

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

- Memoization avoids repeated recursive computations.
- Tabulation builds the solution iteratively from the base cases.
- Since each state depends only on the previous two states, the DP array can be optimized to constant space.
