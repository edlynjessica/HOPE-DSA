## 📖 Problem Statement

A secret message is encoded using the mapping:

```
1 -> A
2 -> B
...
26 -> Z
```

Given a string containing only digits, return the **total number of valid ways** to decode the entire string.

A leading zero is **not valid**, and only numbers from **10 to 26** can be decoded as two-digit letters.

---

# 💡 Observation

At every position, there are at most **two possible choices**:

- Decode the current digit alone.
- Decode the current digit together with the previous digit.

If either choice is valid, add the number of ways contributed by that choice.

Since every answer depends on previously solved positions, this is a **1D Dynamic Programming** problem.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **number of valid ways** to decode the given string.

---

## What is the subproblem?

Let

```
dp[i]
```

represent the **number of ways to decode the first `i` characters** of the string.

---

## Recurrence Relation

### Case 1 : Decode one digit

If the current digit is not `'0'`

```
dp[i] += dp[i-1]
```

---

### Case 2 : Decode two digits

If the last two digits form a number between

```
10
```

and

```
26
```

```
dp[i] += dp[i-2]
```

---

## Base Cases

```
dp[0] = 1
```

The empty string has one valid decoding.

```
dp[1] = 1
```

Since the first character is already checked to be non-zero, it has exactly one valid decoding.

---

# ✅ Approach 1 : Basic Recursion

### Idea

Recursively try decoding:

- One digit.
- Two digits (if valid).

The total number of decoding ways is the sum of both choices.

Since the same substrings are decoded repeatedly, this approach performs many redundant recursive calls.

### ❌ Result

This approach results in **Time Limit Exceeded (TLE)** for larger strings.

### Time Complexity

```
O(2ⁿ)
```

### Space Complexity

```
O(n)
```

(Recursion Stack)

### Code

```java
class Solution {
    public int numDecodings(String s) {
        if(s.charAt(0)=='0') return 0;
        return helper(0,s);
    }

    static int helper(int i,String s){

        if(i==s.length()) return 1; // valid decoding

        if(s.charAt(i)=='0') return 0; // cannot start with 0

        // Decode one digit
        int one=helper(i+1,s);

        // Decode two digits
        int two=0;

        if(i+1<s.length()){
            if(Integer.parseInt(s.substring(i,i+2))<=26)
                two=helper(i+2,s);
        }

        return one+two;
    }
}
```

# ✅ Approach 2 : Memoization (Top-Down DP)

### Idea

Store the answer for every starting index after computing it once.

If the same substring is encountered again,

simply return the stored answer instead of solving it recursively again.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(n+n)
```

Memo Array + Recursion Stack

### Code

```java
class Solution {

    // memoization approach
    // flow.. base cases -> check memo -> recursive calls -> store result -> return

    static int[] memo;

    public int numDecodings(String s) {

        if(s.charAt(0)=='0') return 0;

        memo=new int[s.length()+1];
        Arrays.fill(memo,-1);

        return helper(0,s);
    }

    static int helper(int i,String s){

        // base cases
        if(i==s.length()) return 1;

        if(s.charAt(i)=='0') return 0;

        if(memo[i]!=-1) return memo[i];

        // Decode one digit
        int one=helper(i+1,s);

        // Decode two digits
        int two=0;

        if(i+1<s.length()){

            int num=(s.charAt(i)-'0')*10+s.charAt(i+1)-'0';

            if(num>=10 && num<=26)
                two=helper(i+2,s);
        }

        memo[i]=one+two;

        return memo[i];
    }
}
```

# ✅ Approach 3 : Tabulation (Bottom-Up DP)

### Idea

Build the DP array from left to right.

For every position,

check whether the current digit can be decoded alone,

and whether the last two digits together form a valid letter.

Add the number of decoding ways contributed by each valid choice.

---

### Time Complexity

```
O(n)
```

---

### Space Complexity

```
O(n)
```

---

### Code

```java
class Solution {
    public int numDecodings(String s) {
        // Tabulation approach
        if(s.charAt(0)=='0') return 0; // if string starts with 0, no valid decoding

        int n=s.length();
        int[] dp=new int[n+1];

        // base cases
        dp[0]=1; // empty string ""
        dp[1]=1; // first character is already checked to be non-zero

        for(int i=2;i<=n;i++){

            // Case 1 : Decode one digit
            if(s.charAt(i-1)!='0'){
                dp[i]+=dp[i-1];
            }

            // Case 2 : Decode two digits
            int td=(s.charAt(i-2)-'0')*10 + s.charAt(i-1)-'0';

            if(td>=10 && td<=26){
                dp[i]+=dp[i-2];
            }
        }

        return dp[n];
    }
}
```

# 🎯 Key Takeaways

- Decode Ways is a classic **Counting DP** problem.
- Define the DP state as:

```
dp[i]
```

= Number of ways to decode the first `i` characters.

- Every position has at most two choices:
  - Decode one digit.
  - Decode two digits.
- The recurrence is:

```
if(current digit is valid)
    dp[i] += dp[i-1]

if(last two digits are valid)
    dp[i] += dp[i-2]
```

- Unlike Coin Change or House Robber, this problem does **not** take a minimum or maximum.
- Instead, it **adds** all valid decoding possibilities.
- Always handle `'0'` carefully since it cannot be decoded by itself.
