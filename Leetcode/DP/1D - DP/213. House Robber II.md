## 📖 Problem Statement

You are a professional robber planning to rob houses arranged **in a circle**.

Each house contains some money, but **adjacent houses cannot both be robbed**.

Since the houses form a circle:

- The **first house** is adjacent to the **last house**.

Return the **maximum amount of money** that can be robbed without robbing two adjacent houses.

---

# 💡 Observation

House Robber I had only one constraint:

- Adjacent houses cannot both be robbed.

Now there is one extra constraint:

- The **first and last houses are also adjacent.**

Therefore,

we can **never rob both the first and last house together.**

So there are only **two possible cases**.

### Case 1

Include the **first house**.

Then the **last house cannot be robbed.**

Solve House Robber on

```text
[0 ... n-2]
```

---

### Case 2

Include the **last house**.

Then the **first house cannot be robbed.**

Solve House Robber on

```text
[1 ... n-1]
```

The answer is the maximum of these two cases.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **maximum amount of money** that can be robbed from a **circular street**.

---

## What is the subproblem?

Exactly the same as House Robber I.

Let

```text
dp[i]
```

represent the **maximum money that can be robbed up to house `i`.**

---

## Recurrence Relation

Same as House Robber I.

```text
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

---

## Base Cases

For Case 1

```text
dp1[0] = nums[0]

dp1[1] = max(nums[0], nums[1])
```

---

For Case 2

```text
dp2[0] = 0

dp2[1] = nums[1]
```

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Run the House Robber DP **twice**.

- First DP ignores the last house.
- Second DP ignores the first house.

Finally,

return the larger answer.

---

### Time Complexity

```text
O(n)
```

---

### Space Complexity

```text
O(n)
```

Two DP arrays are used.

---

### Code

```java
class Solution {
    public int rob(int[] nums) {

        int n = nums.length;

        if(n == 1) return nums[0];
        if(n == 2) return Math.max(nums[0], nums[1]);

        int[] dp1 = new int[n]; // include first house
        int[] dp2 = new int[n]; // include last house

        // Case 1 : Rob from house 0 to n-2
        dp1[0] = nums[0];
        dp1[1] = Math.max(nums[0], nums[1]);

        for(int i = 2; i < n-1; i++){
            dp1[i] = Math.max(dp1[i-1], dp1[i-2] + nums[i]);
        }

        // Case 2 : Rob from house 1 to n-1
        dp2[0] = 0;
        dp2[1] = nums[1];

        for(int i = 2; i < n; i++){
            dp2[i] = Math.max(dp2[i-1], dp2[i-2] + nums[i]);
        }

        // either add first house or last house
        // (circular array, so first and last are neighbours)
        return Math.max(dp1[n-2], dp2[n-1]);
    }
}
```

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Tabulation | O(n) | O(n) |

# 🎯 Key Takeaways

- House Robber II is an extension of **House Robber I**.
- The only new challenge is the **circular arrangement**.
- Since the first and last houses are adjacent, they **cannot both be robbed**.
- Split the problem into two independent House Robber problems:
  - Rob houses **0 → n-2**
  - Rob houses **1 → n-1**
- Solve both using the House Robber I recurrence:

```text
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

- The final answer is:

```text
max(case1, case2)
```

# 🔄 Relation to House Robber I

| House Robber I | House Robber II |
|----------------|-----------------|
| Houses are in a straight line | Houses are arranged in a circle |
| One DP run | Two DP runs |
| Answer = `dp[n-1]` | Answer = `max(case1, case2)` |
| Recurrence: `max(skip, rob)` | Same recurrence, applied twice |
