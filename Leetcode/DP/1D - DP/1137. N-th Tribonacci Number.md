# 1137. N-th Tribonacci Number

![Language](https://img.shields.io/badge/Language-Java-orange?style=for-the-badge)
![Difficulty](https://img.shields.io/badge/Difficulty-Easy-green?style=for-the-badge)
![Topic](https://img.shields.io/badge/Topic-1D%20Dynamic%20Programming-blue?style=for-the-badge)

---

## 📖 Problem Statement

The Tribonacci sequence is defined as:

```
T0 = 0
T1 = 1
T2 = 1
```

For every `n ≥ 0`,

```
Tn+3 = Tn + Tn+1 + Tn+2
```

Given an integer `n`, return the value of `Tn`.

---

# 💡 Observation

The value of the current Tribonacci number depends only on the previous **three** Tribonacci numbers.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **nᵗʰ Tribonacci number**.

---

## What is the subproblem?

Let

```
dp[i]
```

represent the **iᵗʰ Tribonacci number**.

---

## Recurrence Relation

Every Tribonacci number is the sum of the previous three numbers.

```
dp[i] = dp[i-1] + dp[i-2] + dp[i-3]
```

---

## Base Cases

```
dp[0] = 0

dp[1] = 1

dp[2] = 1
```

---

# ✅ Approach 1 : Basic Recursion

### Idea

Recursively calculate the previous three Tribonacci numbers and return their sum.

Since the same subproblems are solved repeatedly, this approach performs a large number of redundant calculations.

### ❌ Result

This approach results in **Time Limit Exceeded (TLE)** for larger values of `n`.

### Time Complexity

```
O(3ⁿ)
```

### Space Complexity

```
O(n)
```

(Recursion Stack)

### Code

```java
class Solution {
    public int tribonacci(int n) {
        if(n==0) return 0;
        if(n==1 || n==2) return 1;
        return tribonacci(n-1)+tribonacci(n-2)+tribonacci(n-3);
    }
}
```

---

# ✅ Approach 2 : Memoization (Top-Down DP)

### Idea

Store the answer for every Tribonacci number after computing it once.

If the value has already been calculated, simply return the stored answer.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(n)
```

DP Array

+

```
O(n)
```

Recursion Stack

### Code

```java
class Solution {
    // memoization
    static int[] dp;
    public int tribonacci(int n) {
        dp=new int[n+1];
        Arrays.fill(dp,-1);
        return memo(n);
    }
    public int memo(int n){
        if(n==0) return 0;
        if(n==1 || n==2) return 1;
        if(dp[n]!=-1) return dp[n];
        dp[n]=memo(n-1)+memo(n-2)+memo(n-3);
        return dp[n];
    }
}
```

---

# ✅ Approach 3 : Tabulation (Bottom-Up DP)

### Idea

Start from the known base cases.

Build the DP array from left to right using the recurrence relation.

Each state depends on the previous three states.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(n)
```

### Code

```java
class Solution {
    // tabulation
    public int tribonacci(int n) {
        if(n==0) return 0;
        if(n==1 || n==2) return 1;

        int[] dp=new int[n+1];

        dp[0]=0;
        dp[1]=1;
        dp[2]=1;

        for(int i=3;i<=n;i++){
            dp[i]=dp[i-1]+dp[i-2]+dp[i-3];
        }

        return dp[n];
    }
}
```

---

# ✅ Approach 4 : Space Optimized DP

### Idea

Observe that every state depends only on the previous **three** states.

Instead of storing the entire DP array, we only keep track of the last three Tribonacci numbers.

This reduces the space complexity from **O(n)** to **O(1)**.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(1)
```

### Code

```java
class Solution {
    // space optimized
    public int tribonacci(int n) {
        if(n==0) return 0;
        if(n==1 || n==2) return 1;

        int t0=0;
        int t1=1;
        int t2=1;
        int t3=0;

        for(int i=3;i<=n;i++){
            t3=t0+t1+t2;
            t0=t1;
            t1=t2;
            t2=t3;
        }

        return t2;
    }
}
```

# 📊 Complexity Comparison

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Basic Recursion | O(3ⁿ) | O(n) |
| Memoization | O(n) | O(n) + O(n) |
| Tabulation | O(n) | O(n) |
| Space Optimized | O(n) | O(1) |

---

# 🎯 Key Takeaways

- Tribonacci is an extension of the Fibonacci sequence.
- Each state depends on the previous **three** states instead of two.
- Define the DP state as:

```
dp[i]
```

= The `iᵗʰ` Tribonacci number.

- The recurrence relation is:

```
dp[i] = dp[i-1] + dp[i-2] + dp[i-3]
```

- Basic recursion performs many repeated computations, leading to **TLE**.
- Memoization eliminates repeated calculations by caching computed states.
- Tabulation computes the answer iteratively from the base cases.
