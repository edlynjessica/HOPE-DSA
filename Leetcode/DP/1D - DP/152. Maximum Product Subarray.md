## 📖 Problem Statement

Given an integer array `nums`, find a **contiguous non-empty subarray** that has the largest product, and return the product.

---

# 💡 Observation

Unlike the Maximum Sum Subarray problem, multiplication behaves differently because of **negative numbers**.

- A positive number keeps the sign unchanged.
- A negative number flips the sign.
- Two negative numbers multiplied together become positive.

Therefore, a **minimum product** can suddenly become the **maximum product** after multiplying by a negative number.

This means we must track **both the maximum and minimum product** ending at every index.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **maximum product** of any contiguous subarray.

---

## What is the subproblem?

At every index `i`, maintain two DP states.

```
maxEndingHere
```

Maximum product of a subarray ending at index `i`.

```
minEndingHere
```

Minimum product of a subarray ending at index `i`.

---

## Why do we need two DP states?

Consider the array

```
[-2, 3, -4]
```

The minimum product

```
-6
```

when multiplied by

```
-4
```

becomes

```
24
```

which is the new maximum product.

Hence, tracking only the maximum product is not sufficient.

---

## Transition

If the current number is negative,

the maximum and minimum products swap their roles.

```
maxEndingHere = max(nums[i], maxEndingHere × nums[i])

minEndingHere = min(nums[i], minEndingHere × nums[i])
```

The overall answer is the maximum value of `maxEndingHere`.

---

# ✅ Approach : Space Optimized DP

### Idea

Instead of maintaining two DP arrays,

store only the previous maximum and minimum products.

Since every state depends only on the previous state,

the DP can be optimized to constant space.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(1)
```

### Code

```java
class Solution {
    public int maxProduct(int[] nums) {
        int max = nums[0], min = nums[0], ans = nums[0];

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] < 0) {
                int temp = max;
                max = min;
                min = temp;
            }

            max = Math.max(nums[i], max * nums[i]);
            min = Math.min(nums[i], min * nums[i]);

            ans = Math.max(ans, max);
        }

        return ans;
    }
}
```

---

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Space Optimized DP | O(n) | O(1) |

---

# 🎯 Key Takeaways

- This is a **1D Dynamic Programming** problem.
- A single DP state is not enough because negative numbers can reverse the sign of the product.
- Maintain both:
  - Maximum product ending at the current index.
  - Minimum product ending at the current index.
- Swap the two states whenever a negative number is encountered.
- Since only the previous state is required, the solution is optimized to **O(1)** space.
