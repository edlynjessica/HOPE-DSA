## 📖 Problem Statement

The Fibonacci numbers, commonly denoted **F(n)**, form a sequence called the **Fibonacci Sequence**, where each number is the sum of the previous two numbers.

```
F(0) = 0
F(1) = 1

F(n) = F(n-1) + F(n-2), for n > 1
```

Given an integer **n**, return the **nᵗʰ Fibonacci number**.

---

# 💡 Observation

Every Fibonacci number depends only on the previous two Fibonacci numbers.

```
F(5)

↓

F(4) + F(3)

↓

(F(3) + F(2)) + (F(2) + F(1))
```

Notice that **F(3)** and **F(2)** are calculated multiple times.

This indicates **Overlapping Subproblems**, making it a perfect Dynamic Programming problem.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **nᵗʰ Fibonacci number**.

---

## What is the subproblem?

Let

```
fib(i)
```

represent the **iᵗʰ Fibonacci number**.

---

## Recurrence Relation

```
fib(i) = fib(i-1) + fib(i-2)
```

---

## Base Cases

```
fib(0) = 0

fib(1) = 1
```

---

# ✅ Approach 1 : Basic Recursion

### Idea

Solve the problem recursively.

For every Fibonacci number,

- calculate `fib(n-1)`
- calculate `fib(n-2)`
- return their sum.

### Time Complexity

```
O(2ⁿ)
```

### Space Complexity

```
O(n)
```

(Recursion Stack)

### Code

```java
class Solution {
    // Basic Recursive Approach
    public int fib(int n) {
        // Base Cases
        if (n == 0 || n == 1)
            return n;
        // Recursive Calls
        return fib(n - 1) + fib(n - 2);
    }
}
```

---

# ✅ Approach 2 : Memoization (Top-Down DP)

### Idea

Instead of recalculating the same Fibonacci number repeatedly,

store it after computing it once.

Whenever it is needed again,

simply return the stored value.

### Algorithm

- Create a DP array.
- Initialize every value with `-1`.
- Solve recursively.
- Before computing,
  check if the answer is already stored.
- If yes,
  return it.
- Otherwise,
  compute and store it.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(n)
```

DP Array

+

```
O(n)
```

Recursion Stack

### Code

```java
class Solution {
    // Memoization DP Approach

    static int[] dp;
    public int fib(int n){
        dp=new int[n+1];
        Arrays.fill(dp,-1);
        return memoize(n);
    }
    public int memoize(int n){
        if(n==1 || n==0) return n;
        if(dp[n]!=-1) return dp[n];
        dp[n]=memoize(n-1)+memoize(n-2);
        return dp[n];
    }
}
```

# ✅ Approach 3 : Tabulation (Bottom-Up DP)

### Idea

Instead of starting from `fib(n)`,

start from the known values.

```
fib(0)

↓

fib(1)

↓

fib(2)

↓

...

↓

fib(n)
```

Build the DP table from left to right.

### Algorithm

- Create a DP array.
- Initialize the base cases.
- Fill the remaining values using the recurrence relation.
- Return the last value.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(n)
```

### Code

```java
class Solution {
    // Tabulation DP Approach

    public int fib(int n) {
        if (n == 0 || n == 1)
            return n;
        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = 1;
        // Build DP Table
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}
```

# ✅ Approach 4 : Space Optimized DP

### Observation

To calculate

```
fib(i)
```

we only require

```
fib(i-1)

and

fib(i-2)
```

Therefore,

there is no need to maintain the entire DP array.

We only keep the previous two Fibonacci numbers.

### Time Complexity

```
O(n)
```

### Space Complexity

```
O(1)
```

### Code

```java 
class Solution {
    // Space Optimized DP Approach
    public int fib(int n) {
        if(n==1 || n==0) return n;
        int n1=0;
        int n2=1;
        int n3=1;
        while(n>1){
            n3=n1+n2;
            n1=n2;
            n2=n3;
            n--;
        }
        return n3;
    }
}
```

# 📊 Complexity Comparison

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Basic Recursion | O(2ⁿ) | O(n) |
| Memoization | O(n) | O(n) + O(n) |
| Tabulation | O(n) | O(n) |
| Space Optimized | O(n) | O(1) |

---

# 🎯 Key Takeaways

- Fibonacci is one of the simplest Dynamic Programming problems.
- The recursive solution performs repeated calculations.
- Memoization eliminates repeated computations by storing answers.
- Tabulation builds the solution iteratively from the base cases.
- Since each Fibonacci number depends only on the previous two numbers, the DP array can be optimized to constant space.
