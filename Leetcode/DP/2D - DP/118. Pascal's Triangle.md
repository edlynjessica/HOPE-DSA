## 📖 Problem Statement

Given an integer `numRows`, return the first `numRows` of **Pascal's Triangle**.

Each number in Pascal's Triangle is the **sum of the two numbers directly above it**.

Example:

```text
            1
          1   1
        1   2   1
      1   3   3   1
    1   4   6   4   1
```

---

# 💡 Observation

Every row always:

- Starts with **1**
- Ends with **1**
- Every middle element is obtained by adding the two elements above it.

For row `i`,

```text
curr[j] = prev[j-1] + prev[j]
```

where `prev` is the previous row.

---

# 🧠 DP Thinking

## What does the question ask?

Generate the first `numRows` rows of Pascal's Triangle.

---

## What is the subproblem?

Let

```text
dp[i]
```

represent the **entire `iᵗʰ` row** of Pascal's Triangle.

---

## Recurrence Relation

For every middle element,

```text
curr[j] = prev[j-1] + prev[j]
```

where

```text
prev = dp[i-1]
```

---

## Base Case

The first row is always

```text
[1]
```

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Start with the first row.

For every new row:

- Add `1` at the beginning.
- Generate all middle elements using the previous row.
- Add `1` at the end.

Repeat until all rows are generated.

---

### Time Complexity

```text
O(numRows²)
```

---

### Space Complexity

```text
O(numRows²)
```

since all rows are stored.

---

### Code

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {

        List<List<Integer>> dp = new ArrayList<>();
        List<Integer> first = new ArrayList<>();
        first.add(1);
        dp.add(first);
        if(numRows == 1)
            return dp;

        for(int i = 1; i < numRows; i++){
            List<Integer> prev = dp.get(i-1);
            List<Integer> curr = new ArrayList<>();
            // first element
            curr.add(1);
            // middle elements
            for(int j = 1; j < prev.size(); j++){
                curr.add(prev.get(j-1) + prev.get(j));
            }
            // last element
            curr.add(1);

            dp.add(curr);
        }
        return dp;
    }
}
```

---

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Tabulation | O(numRows²) | O(numRows²) |

# 🎯 Key Takeaways

- Pascal's Triangle follows a simple **2D DP** pattern.
- Define the DP state as:

```text
dp[i]
```

= The complete `iᵗʰ` row of Pascal's Triangle.

- Every row starts and ends with **1**.
- Every middle element is calculated as:

```text
prev[j-1] + prev[j]
```

- Each row depends only on the **previous row**, making it a straightforward Bottom-Up DP problem.
