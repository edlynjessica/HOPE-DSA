## 📖 Problem Statement

A robot is placed at the **top-left corner** of an `m × n` grid.

The robot wants to reach the **bottom-right corner**.

It can only move:

- **Right**
- **Down**

Return the total number of **unique paths** the robot can take to reach the destination.

---

# 💡 Observation

To reach any cell, there are only **two possible ways**.

- Move **down** from the cell above.
- Move **right** from the cell on the left.

Therefore, the number of paths to the current cell is simply the sum of the paths to these two cells.

This makes it a classic **2D Dynamic Programming** problem.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **total number of unique paths** from the top-left corner to the bottom-right corner.

---

## What is the subproblem?

Let

```
dp[i][j]
```

represent the **number of unique paths to reach cell `(i, j)`**.

---

## Recurrence Relation

To reach cell `(i, j)`, the robot can come only from:

- the cell above `(i-1, j)`
- the cell on the left `(i, j-1)`

Therefore,

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

---

## Base Cases

### First Column

Every cell in the first column can only be reached by moving **down**.

```
dp[i][0] = 1
```

---

### First Row

Every cell in the first row can only be reached by moving **right**.

```
dp[0][j] = 1
```

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Start from the known base cases.

Build the DP table row by row.

Each cell stores the number of unique paths required to reach that position.

Finally, the bottom-right cell contains the required answer.


### Time Complexity

```
O(m × n)
```

### Space Complexity

```
O(m × n)
```

### Code

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp=new int[m][n];

        // base cases

        // 1st col can be reached only by moving down
        for(int i=0;i<m;i++){
            dp[i][0]=1;
        }

        // 1st row can be reached only by moving right
        for(int j=0;j<n;j++){
            dp[0][j]=1;
        }

        for(int i=1;i<m;i++){
            for(int j=1;j<n;j++){
                dp[i][j]=dp[i-1][j]+dp[i][j-1];
            }
        }

        // final number of unique paths
        return dp[m-1][n-1];
    }
}
```

---

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Tabulation | O(m × n) | O(m × n) |

---

# 🎯 Key Takeaways

- Unique Paths is one of the simplest **2D Dynamic Programming** problems.
- Define the DP state as:

```
dp[i][j]
```

= Number of unique paths to reach cell `(i, j)`.

- Each cell depends only on:
  - the cell above
  - the cell on the left

- The recurrence relation is:

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

- The first row and first column always contain **1**, since there is only one possible way to reach those cells.

- The final answer is stored in:

```
dp[m-1][n-1]
```
