# 63. Unique Paths II

## 📖 Problem Statement

A robot starts at the **top-left corner** of an `m × n` grid and wants to reach the **bottom-right corner`.

The robot can move only:

- Right
- Down

Some cells contain **obstacles (`1`)**, while empty cells are represented by **`0`**.

The robot **cannot move through an obstacle**.

Return the **total number of unique paths** from the start to the destination.

---

# 💡 Observation

This problem is almost identical to **Unique Paths**.

The only difference is that **some cells are blocked**.

If a cell contains an obstacle,

there are **zero ways** to reach it.

Otherwise,

the number of ways to reach a cell is the sum of the ways to reach:

- the cell above
- the cell to the left

---

# 🧠 DP Thinking

## What does the question ask?

Find the **number of unique paths** while avoiding obstacles.

---

## What is the subproblem?

Let

```
dp[i][j]
```

represent the **number of unique paths to reach cell `(i, j)`**.

---

## Recurrence Relation

### If the current cell is blocked

```
dp[i][j] = 0
```

---

### Otherwise

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

---

## Base Cases

### Starting Cell

If the starting cell itself is blocked,

```
return 0
```

Otherwise,

```
dp[0][0] = 1
```

---

### First Row

Cells in the first row can only be reached from the **left**.

If an obstacle appears,

every cell after it becomes unreachable.

---

### First Column

Cells in the first column can only be reached from **above**.

If an obstacle appears,

every cell below it becomes unreachable.

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Create a DP table of the same size as the grid.

Initialize:

- starting cell
- first row
- first column

carefully while considering obstacles.

Then fill the remaining cells using the recurrence relation.

---

### Time Complexity

```
O(m × n)
```

---

### Space Complexity

```
O(m × n)
```

---

### Code

```java
class Solution {
    public int uniquePathsWithObstacles(int[][] obstacleGrid) {

        int m=obstacleGrid.length;
        int n=obstacleGrid[0].length;

        // 1st base case, if obstacle is in the 1st cell itself
        if(obstacleGrid[0][0]==1) return 0;

        int[][] dp=new int[m][n];

        dp[0][0]=1;

        // base case -> first row
        boolean blocked=false;

        for(int i=1;i<n;i++){

            if(blocked){
                dp[0][i]=0;
            }
            else{

                if(obstacleGrid[0][i]==0)
                    dp[0][i]=1;
                else{
                    blocked=true;
                    dp[0][i]=0;
                }
            }
        }

        // base case -> first column
        blocked=false;

        for(int i=1;i<m;i++){

            if(blocked)
                dp[i][0]=0;
            else{

                if(obstacleGrid[i][0]==0)
                    dp[i][0]=1;
                else{
                    blocked=true;
                    dp[i][0]=0;
                }
            }
        }

        // calculate remaining cells

        for(int i=1;i<m;i++){

            for(int j=1;j<n;j++){

                if(obstacleGrid[i][j]==1)
                    dp[i][j]=0;
                else
                    dp[i][j]=dp[i-1][j]+dp[i][j-1];
            }
        }

        return dp[m-1][n-1];
    }
}
```

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Tabulation | O(m × n) | O(m × n) |

---

# 🎯 Key Takeaways

- Unique Paths II is a classic **2D Dynamic Programming** problem.
- Define the DP state as:

```
dp[i][j]
```

= Number of unique paths to reach cell `(i, j)`.

- If a cell is an obstacle:

```
dp[i][j] = 0
```

- Otherwise:

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

- The first row and first column require separate initialization because they have only one possible direction of movement.
- Once an obstacle appears in the first row or first column, every cell after it in that direction becomes unreachable.
- This problem is an extension of **Unique Paths**, where blocked cells simply contribute **zero paths**.
