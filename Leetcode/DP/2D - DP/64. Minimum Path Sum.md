# 64. Minimum Path Sum

![Language](https://img.shields.io/badge/Language-Java-orange?style=for-the-badge)

## 📖 Problem Statement

Given an `m × n` grid filled with **non-negative numbers**, find a path from the **top-left** corner to the **bottom-right** corner such that the **sum of all numbers along the path is minimum**.

The robot can move only:

- Right
- Down

Return the **minimum path sum**.

---

# 💡 Observation

This problem is very similar to **Unique Paths**.

Instead of counting the number of paths,

we now need to find the **minimum cost path**.

For every cell,

we can arrive either:

- from the top
- from the left

Choose the path with the **smaller sum**.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **minimum sum** required to reach the bottom-right cell.

---

## What is the subproblem?

Let

```
dp[i][j]
```

represent the **minimum path sum required to reach cell `(i, j)`**.

---

## Recurrence Relation

The current cell can be reached from:

- Top
- Left

Choose the minimum.

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

---

## Base Cases

### Starting Cell

```
dp[0][0] = grid[0][0]
```

---

### First Row

The robot can only move **right**.

```
dp[0][j] = dp[0][j-1] + grid[0][j]
```

---

### First Column

The robot can only move **down**.

```
dp[i][0] = dp[i-1][0] + grid[i][0]
```

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Create a DP table of the same size as the grid.

Initialize:

- starting cell
- first row
- first column

Then,

for every remaining cell,

choose the smaller path sum from the top or left and add the current cell value.

---

### Time Complexity

```
O(m × n)
```

---

### Space Complexity

```
O(m × n)
```

---

### Code

```java
class Solution {
    public int minPathSum(int[][] grid) {

        int m=grid.length;
        int n=grid[0].length;

        int[][] dp=new int[m][n];

        dp[0][0]=grid[0][0]; // base

        // first row
        for(int j=1;j<n;j++){
            dp[0][j]+=dp[0][j-1]+grid[0][j];
        }

        // first column
        for(int i=1;i<m;i++){
            dp[i][0]+=dp[i-1][0]+grid[i][0];
        }

        // calculate remaining cells

        for(int i=1;i<m;i++){
            for(int j=1;j<n;j++){
                dp[i][j]=Math.min(dp[i-1][j],dp[i][j-1])+grid[i][j];
            }
        }

        return dp[m-1][n-1];
    }
}
```

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Tabulation | O(m × n) | O(m × n) |

# 🎯 Key Takeaways

- Minimum Path Sum is a classic **2D Dynamic Programming** problem.
- Define the DP state as:

```
dp[i][j]
```

= Minimum path sum required to reach cell `(i, j)`.

- The recurrence relation is:

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

- The first row can only be reached by moving **right**.
- The first column can only be reached by moving **down**.
- Unlike **Unique Paths**, which **counts** paths, this problem finds the **minimum path cost**.
- At every cell, choose the path with the **smaller accumulated sum**.
