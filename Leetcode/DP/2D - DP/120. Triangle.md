## 📖 Problem Statement

Given a triangle array, return the **minimum path sum** from top to bottom.

At each step, you may move only to one of the **adjacent numbers** in the next row.

From position

```text
(i, j)
```

you may move to

```text
(i+1, j)

or

(i+1, j+1)
```

---

# 💡 Observation

Each cell can be reached from only **two possible parents**.

For a cell

```text
(i, j)
```

the parents are:

```text
(i-1, j-1)

and

(i-1, j)
```

Take the minimum of these two paths and add the current value.

The only exceptions are the **left edge** and **right edge**, since they each have only one parent.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **minimum path sum** from the top of the triangle to any element in the last row.

---

## What is the subproblem?

Let

```text
dp[i][j]
```

represent the **minimum path sum to reach position `(i, j)`**.

---

## Recurrence Relation

### Left Edge

Only one parent exists.

```text
dp[i][0] = triangle[i][0] + dp[i-1][0]
```

---

### Middle Elements

Two parents exist.

```text
dp[i][j] = triangle[i][j] +
           min(dp[i-1][j-1], dp[i-1][j])
```

---

### Right Edge

Only one parent exists.

```text
dp[i][i] = triangle[i][i] + dp[i-1][i-1]
```

---

## Base Case

The top of the triangle is the starting point.

```text
dp[0][0] = triangle[0][0]
```

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Start from the top row.

Build the DP row by row.

For every element,

compute the minimum path sum using its valid parent(s).

Finally,

the answer is the **minimum value in the last row**.

---

### Time Complexity

```text
O(n²)
```

---

### Space Complexity

```text
O(n²)
```

---

### Code

```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {

        int n = triangle.size();
        if(n == 1)  return triangle.get(0).get(0);
        List<List<Integer>> dp = new ArrayList<>();

        // initialize DP rows
        for(int i = 0; i < n; i++)
            dp.add(new ArrayList<>());

        // base case
        dp.get(0).add(triangle.get(0).get(0));

        for(int i = 1; i < n; i++){
            int size = triangle.get(i).size();

            // left edge
            dp.get(i).add(
                triangle.get(i).get(0) +
                dp.get(i-1).get(0)
            );

            // middle elements
            for(int j = 1; j < size - 1; j++){
                int val = triangle.get(i).get(j)
                        + Math.min( dp.get(i-1).get(j-1), dp.get(i-1).get(j));
                dp.get(i).add(val);
            }

            // right edge
            dp.get(i).add(
                triangle.get(i).get(i) +
                dp.get(i-1).get(i-1)
            );
        }

        int ans = Integer.MAX_VALUE;
        for(int val : dp.get(n-1))
            ans = Math.min(ans, val);
        return ans;
    }
}
```

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Tabulation | O(n²) | O(n²) |

---

# 🎯 Key Takeaways

- Triangle is a classic **2D Dynamic Programming** problem.
- Define the DP state as:

```text
dp[i][j]
```

= Minimum path sum to reach position `(i, j)`.

- Every middle element has **two parents**.
- The left and right edges each have **only one parent**.
- Build the solution from **top to bottom**.
- The final answer is the **minimum element in the last DP row**, not necessarily the bottom-right element.

---

# 📌 Transition Summary

```text
                Top

            dp[0][0]

               │

        ┌──────┴──────┐

     dp[i-1][j-1]   dp[i-1][j]

             \       /

              \     /

             dp[i][j]
```

For every middle cell,

```text
dp[i][j] =
triangle[i][j] +
min(left parent, right parent)
```
