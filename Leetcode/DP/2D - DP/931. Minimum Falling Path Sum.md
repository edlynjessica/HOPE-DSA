# 931. Minimum Falling Path Sum

## 📖 Problem Statement

Given an `n × n` matrix, find the **minimum sum** of any **falling path**.

A falling path:

- Starts from **any cell in the first row**.
- At every step, moves to the next row by choosing one of:
  - Down-left
  - Down
  - Down-right

Return the **minimum falling path sum**.

---

# 💡 Observation

Unlike **Minimum Path Sum**, the starting point is **not fixed**.

A path can start from **any column in the first row**.

For every cell,

we can reach it only from the previous row.

There are at most **three possible parent cells**.

---

# 🧠 DP Thinking

## What does the question ask?

Find the **minimum falling path sum** from the first row to the last row.

---

## What is the subproblem?

Let

```
dp[i][j]
```

represent the **minimum falling path sum required to reach cell `(i, j)`**.

---

## Recurrence Relation

A cell can be reached from:

- Top-left
- Top
- Top-right

Choose the minimum.

```
dp[i][j] =
min(dp[i-1][j-1],
    dp[i-1][j],
    dp[i-1][j+1])
+ matrix[i][j]
```

Boundary cells simply ignore invalid parent positions.

---

## Base Cases

Since the path may start from **any cell in the first row**,

```
dp[0][j] = matrix[0][j]
```

for every column.

---

# ✅ Approach : Tabulation (Bottom-Up DP)

### Idea

Create a DP table of the same size as the matrix.

Initialize the first row because every cell can act as a starting point.

Then,

for every remaining cell,

choose the minimum among its valid parent cells and add the current cell value.

Finally,

the answer is the **minimum value in the last row**, since the path may end at any column.

---

### Time Complexity

```
O(n²)
```

---

### Space Complexity

```
O(n²)
```

---

### Code

```java
class Solution {
    public int minFallingPathSum(int[][] matrix) {

        int n=matrix.length;
        int[][] dp=new int[n][n];

        // 1st row base value
        for(int j=0;j<n;j++){
            dp[0][j]=matrix[0][j];
        }

        // at each cell (i,j) ->
        // min((i-1,j-1), (i-1,j), (i-1,j+1)) + matrix[i][j]

        for(int i=1;i<n;i++){
            for(int j=0;j<n;j++){

                if(j>0 && j+1<n){

                    dp[i][j]=Math.min(dp[i-1][j-1],
                             Math.min(dp[i-1][j],
                                      dp[i-1][j+1]))
                             + matrix[i][j];
                }

                else{

                    if(j>0){

                        dp[i][j]=Math.min(dp[i-1][j-1],
                                          dp[i-1][j])
                                          + matrix[i][j];
                    }

                    else if(j+1<n){

                        dp[i][j]=Math.min(dp[i-1][j+1],
                                          dp[i-1][j])
                                          + matrix[i][j];
                    }
                }
            }
        }

        int min=Integer.MAX_VALUE;

        for(int j=0;j<n;j++){
            if(dp[n-1][j]<min)
                min=dp[n-1][j];
        }

        return min;
    }
}
```

# 🎯 Key Takeaways

- Minimum Falling Path Sum is a classic **2D Dynamic Programming** problem.
- Define the DP state as:

```
dp[i][j]
```

= Minimum falling path sum required to reach cell `(i, j)`.

- Each cell has **three possible parent cells**:
  - Top-left
  - Top
  - Top-right

- The recurrence relation is:

```
dp[i][j] =
min(dp[i-1][j-1],
    dp[i-1][j],
    dp[i-1][j+1])
+ matrix[i][j]
```

- The first row acts as the base case because the path can start from **any column**.

- The final answer is **not necessarily the bottom-right cell**.

- Instead, it is the **minimum value in the last row**, since the falling path may end anywhere.
