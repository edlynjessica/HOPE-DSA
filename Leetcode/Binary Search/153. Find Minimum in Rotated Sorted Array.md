## 📖 Problem Statement

Given an ascending sorted array that has been **rotated**, find the **minimum element**.

All elements are **unique**.

The solution must run in:

```text
O(log n)
💡 Observation

A rotated sorted array consists of two sorted portions.

For example:

[4,5,6,7,0,1,2]

can be viewed as:

[4,5,6,7] [0,1,2]

Both portions are individually sorted.

The minimum element is the point where the rotation happens.

🧠 Key Idea

At every step, use mid to determine which side contains the minimum.

We check:

nums[left] <= nums[mid]
Case 1 : Left Side is Sorted

If:

nums[left] <= nums[mid]

then:

left → mid

is sorted.

Therefore, the smallest element in this portion is:

nums[left]

So:

min = Math.min(min, nums[left]);

But the minimum could still be somewhere in the right portion.

Therefore:

left = mid + 1;
Case 2 : Right Side is Sorted

Otherwise:

mid → right

is sorted.

Therefore, the smallest element in this portion is:

nums[mid]

So:

min = Math.min(min, nums[mid]);

Now search the left portion:

right = mid - 1;
🧪 Dry Run

Consider:

nums = [4,5,6,7,0,1,2]

🔍 Why Do We Store min?

Unlike normal Binary Search, we are not directly searching for a specific target.

We are trying to find the minimum value.

At every iteration, we identify a sorted portion and know its smallest possible value.

So we keep track of the best answer found so far:

min = Math.min(min, candidate);

This is why we can safely discard the portion after recording its minimum candidate.

✅ Approach : Modified Binary Search
Time Complexity
O(log n)

The search space is reduced roughly by half in every iteration.

Space Complexity
O(1)

Only constant extra variables are used.

Code
class Solution {

    public int findMin(int[] nums) {

        int min=Integer.MAX_VALUE;
        int n=nums.length;

        int left=0;
        int right=n-1;

        while(left<=right){

            int mid=left+(right-left)/2;

            // Left side is sorted
            if(nums[left]<=nums[mid]){

                // Since left side is sorted,
                // nums[left] is its minimum
                min=Math.min(min,nums[left]);

                // Search the right space
                left=mid+1;

            }else{

                // Right side is sorted,
                // nums[mid] is its minimum
                min=Math.min(nums[mid],min);

                // Search the left space
                right=mid-1;
            }
        }

        return min;
    }
}
📊 Complexity
Approach	Time Complexity	Space Complexity
Modified Binary Search	O(log n)	O(1)
🎯 Key Takeaways
A rotated sorted array contains two sorted portions.
The minimum is located around the rotation point.
Use:
nums[left] <= nums[mid]

to determine whether the left portion is sorted.

If the left portion is sorted:
nums[left] is its minimum.
Search the right portion.
Otherwise:
The right portion is sorted.
nums[mid] is its minimum.
Search the left portion.
Keep a global min because the minimum candidate can be found from different portions during the search.
This is another example of Modified Binary Search with:
O(log n) time
O(1) space
