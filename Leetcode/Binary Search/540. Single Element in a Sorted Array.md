## 📖 Problem Statement

Given a sorted array where:

- Every element appears **exactly twice**.
- Exactly **one element appears only once**.

Find and return the single element.

The solution must run in:

```text
O(log n)

with:

O(1)

extra space.

💡 Observation

Consider:

[1,1,2,2,3,4,4,5,5]

Before the single element 3, the pairs follow this index pattern:

index:  0 1  2 3  4
value:  1 1  2 2  3
         ↑    ↑    ↑
       even odd

After the single element, the pairing pattern changes:

index:  5 6  7 8
value:  4 4  5 5
         ↑ ↑
       odd even

So:

Before the single element

Pairs occur at:

(even, odd)
After the single element

Pairs occur at:

(odd, even)

This change in the pairing pattern allows us to use Binary Search.

🧠 Key Idea

For a valid pair before the single element:

even index → odd index

For example:

index:  2 3
value:  2 2

After the single element:

odd index → even index

For example:

index:  5 6
value:  4 4

Therefore, we can use the index parity around mid to determine which half contains the single element.

🔍 How We Check mid

First, check whether mid itself is the answer.

if(nums[mid]!=nums[mid-1] && nums[mid]!=nums[mid+1])
    return nums[mid];

If it is not the answer, we determine which side contains the single element.

Case 1 : We Are in the Left Half

There are two equivalent patterns indicating that mid belongs to the left half.

Pattern 1

mid is odd and pairs with the previous element:

mid = odd
mid - 1 = even

nums[mid-1] == nums[mid]
Pattern 2

mid is even and pairs with the next element:

mid = even
mid + 1 = odd

nums[mid] == nums[mid+1]

In both cases, the normal pairing pattern is still intact.

Therefore, the single element must be to the right.

left = mid + 1;
Case 2 : We Are in the Right Half

Otherwise, the pairing pattern has already been disrupted.

Therefore, the single element is to the left:

right = mid - 1;

⚠️ Base Cases

Before performing Binary Search, handle the edges.

Only one element
if(n==1)
    return nums[0];
First element is single
if(nums[0]!=nums[1])
    return nums[0];
Last element is single
if(nums[n-1]!=nums[n-2])
    return nums[n-1];

This allows the main Binary Search to safely check:

mid - 1
mid
mid + 1
✅ Approach : Modified Binary Search
Time Complexity
O(log n)

The search space is reduced by approximately half every iteration.

Space Complexity
O(1)

Only constant extra variables are used.

Code
class Solution {

    public int singleNonDuplicate(int[] nums) {

        int n=nums.length;

        // Base cases
        if(n==1) return nums[0];

        // If first element is the single element
        if(nums[0]!=nums[1]) return nums[0];

        // If last element is the single element
        if(nums[n-1]!=nums[n-2]) return nums[n-1];

        int left=1;
        int right=n-2;

        while(left<=right){

            int mid=left+(right-left)/2;

            // Check if mid is the single element
            if(nums[mid]!=nums[mid-1] && nums[mid]!=nums[mid+1])
                return nums[mid];

            /*
             * If:
             * mid is odd  and nums[mid-1] == nums[mid]
             * OR
             * mid is even and nums[mid] == nums[mid+1]
             *
             * then we are in the left half.
             * The single element is to the right.
             */
            if((mid%2==1 && nums[mid-1]==nums[mid]) ||
               (mid%2==0 && nums[mid]==nums[mid+1])){

                left=mid+1;

            }else{

                // We are in the right half
                // Single element is to the left
                right=mid-1;
            }
        }

        return -1;
    }
}
📊 Complexity
Approach	Time Complexity	Space Complexity
Modified Binary Search	O(log n)	O(1)
🎯 Key Takeaways
The array is sorted and every element appears twice except one.
Before the single element, pairs follow:
(even, odd)
After the single element, pairs follow:
(odd, even)
The single element causes this pairing pattern to shift.
Binary Search uses this shift to determine which half contains the answer.
Always check mid first.
Handle the first and last elements separately so that mid-1 and mid+1 are safe.
This is another example of Modified Binary Search.
Time  : O(log n)
Space : O(1)
