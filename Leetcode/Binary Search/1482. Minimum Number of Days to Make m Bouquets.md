# 1482. Minimum Number of Days to Make m Bouquets

---

## 📖 Problem Statement

Given:

```text
bloomDay[i] = day on which the ith flower blooms
m = number of bouquets needed
k = number of adjacent flowers required for each bouquet
```

Find the minimum number of days we need to wait to make at least m bouquets.

Each bouquet requires exactly k adjacent bloomed flowers.

If it is impossible to make m bouquets, return:
```
-1
```

--- 

## 💡 Key Observation

This is another example of:

Binary Search on Answer

We are not searching for a value inside bloomDay.

Instead, we are searching for:

minimum number of days

For any given day d, we can ask:

Can we make at least m bouquets by day d?

This gives us a monotonic condition.

🧠 Why Can We Use Binary Search?

Suppose:

bloomDay = [1,10,3,10,2]
m = 3
k = 1

As days increase, more flowers become available.

For example:

Day 1  → ❌ cannot make 3 bouquets
Day 2  → ❌ cannot make 3 bouquets
Day 3  → ✅ can make 3 bouquets
Day 4  → ✅ can make 3 bouquets
...
Day 10 → ✅ can make 3 bouquets

The pattern is:

❌ ❌ ❌ ✅ ✅ ✅ ✅
            ↑
       first valid day

We want the first day that satisfies the condition.

Therefore, Binary Search works.

🎯 Search Space

We need to search between the earliest and latest blooming days.

Minimum Possible Day
min(bloomDay)

This is the earliest day on which anything can be made.

Maximum Possible Day
max(bloomDay)

By this day, every flower has bloomed.

Therefore:

Search Space = [min(bloomDay), max(bloomDay)]
⚠️ First Check: Is It Even Possible?

Each bouquet requires k flowers.

For m bouquets:

Required flowers = m × k

If:

m × k > n

there are not enough flowers.

So immediately return:

-1

Since m and k can be large, use long for the multiplication:

if((long)m * k > n)
    return -1;
🌸 How Do We Check a Given Day?

Suppose:

mid = 5

We consider every flower:

bloomDay[i] <= 5

means:

Flower has bloomed ✅

Otherwise:

Flower has not bloomed ❌

We need adjacent bloomed flowers.

So we maintain:

c = consecutive bloomed flowers

Whenever:

bloomDay[i] <= mid

increase:

c++;

When:

c == k

we have enough adjacent flowers for one bouquet:

b++;
c = 0;

Resetting c is important because those flowers have already been used.

🧪 Dry Run

Consider:

bloomDay = [1,10,3,10,2]
m = 3
k = 1

Try:

mid = 3

Flowers that have bloomed by day 3:

[1, 10, 3, 10, 2]
 ↓   ↓   ↓   ↓   ↓

[✅, ❌, ✅, ❌, ✅]

Since:

k = 1

every bloomed flower can form one bouquet.

Therefore:

Bouquets = 3

We need:

m = 3

So day 3 works.

Therefore:

ans = 3
right = mid - 1

We now search for an even smaller valid day.

🔄 Important Part: Adjacent Flowers

Consider:

bloomDay = [7,7,7,7,12,7,7]
m = 2
k = 3

At day 7:

[✅, ✅, ✅, ✅, ❌, ✅, ✅]

The first four flowers are adjacent.

We can make:

[✅, ✅, ✅] → Bouquet 1
[✅]         → leftover

After the unbloomed flower:

[✅, ✅]

Only two consecutive flowers remain.

So:

Bouquets = 1

We need:

m = 2

Therefore day 7 is not enough.

Try day 12:

[✅, ✅, ✅, ✅, ✅, ✅, ✅]

Now:

[1,2,3] → Bouquet 1
[4,5,6] → Bouquet 2

So:

Bouquets = 2

Day 12 works.

Therefore:

Answer = 12
🔍 Binary Search Logic

For every candidate day mid:

If enough bouquets can be made
if(b >= m)

Then mid is a valid answer.

But we want the minimum valid day.

So:

ans = mid;
right = mid - 1;

Search earlier days.

If not enough bouquets can be made
b < m

Then mid is too early.

We need to wait longer:

left = mid + 1;
💻 Code
class Solution {

    public int minDays(int[] bloomDay, int m, int k) {

        int n = bloomDay.length;

        // Not enough flowers to make m bouquets
        if((long)m * k > n)
            return -1;

        int min = Integer.MAX_VALUE;
        int max = 0;

        // Find the search space
        for(int day : bloomDay){
            min = Math.min(min, day);
            max = Math.max(max, day);
        }

        int left = min;
        int right = max;
        int ans = 0;

        while(left <= right){

            int mid = left + (right - left) / 2;

            int bouquets = 0;
            int consecutive = 0;

            // Check how many bouquets can be made by 'mid' days
            for(int i = 0; i < n; i++){

                if(bloomDay[i] <= mid){

                    // Flower has bloomed
                    consecutive++;

                    // We have k adjacent flowers
                    if(consecutive == k){
                        bouquets++;
                        consecutive = 0;
                    }

                }else{

                    // Broken adjacency
                    consecutive = 0;
                }
            }

            if(bouquets >= m){

                // mid is a valid answer
                ans = mid;

                // Try to find an earlier day
                right = mid - 1;

            }else{

                // Not enough bouquets
                // Need more days
                left = mid + 1;
            }
        }

        return ans;
    }
}
📊 Complexity

Let:

n = number of flowers
D = max(bloomDay)

Finding the minimum and maximum:

O(n)

For every Binary Search iteration, we scan the flowers:

O(n)

The number of Binary Search iterations is:

O(log D)

Therefore:

Time Complexity
O(n log D)
Space Complexity
O(1)
🎯 Key Takeaways

This is another classic:

Binary Search on Answer

We are searching for:

minimum number of days

The condition is:

Can we make at least m bouquets by this day?

The condition is monotonic:

Too early                  Enough days
    ↓                           ↓

❌ ❌ ❌ ❌ ❌ ✅ ✅ ✅ ✅ ✅
                  ↑
          minimum valid day
Remember the pattern:
1. Define the answer search space.
2. Pick mid.
3. Check whether mid satisfies the condition.
4. If valid → save answer and search left.
5. If invalid → search right.

Here:

Search Space → [min(bloomDay), max(bloomDay)]

Condition → Can we make m bouquets?

Valid → right = mid - 1

Invalid → left = mid + 1
