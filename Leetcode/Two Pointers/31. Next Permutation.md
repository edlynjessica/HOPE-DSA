## 📖 Problem Statement

Given an array of integers representing a permutation, rearrange it into the **next lexicographically greater permutation**.

If no such permutation exists, rearrange it into the **smallest possible permutation** (ascending order).

The rearrangement must be done:

- **In-place**
- Using **O(1)** extra space.

---

# 💡 Observation

A permutation increases lexicographically when we make the **smallest possible change** from the right side.

The right side of the array changes the fastest.

Therefore,

we scan **from right to left** looking for the first place where the sequence stops decreasing.

---

# 🧠 Intuition

Suppose we have

```text
1 2 3 6 5 4
```

Notice that

```text
6 5 4
```

is already in **descending order**.

This is the **largest possible arrangement** using these three numbers.

So no matter how we rearrange only

```text
6 5 4
```

we can never obtain the next greater permutation.

Therefore,

we must modify something **before** this suffix.

That element is called the **pivot**.

---

# 🔑 Algorithm

There are only **4 steps**.

---

## Step 1 : Find the Pivot

Traverse from right to left.

Find the first index such that

```text
nums[i] < nums[i+1]
```

This is called the **pivot**.

Everything to its right is already in descending order.

---

## Step 2 : Find the Successor

Again,

start from the right.

Find the **first element greater than the pivot**.

Because the suffix is descending,

the first greater element from the right is the **smallest possible number** greater than the pivot.

This gives the next lexicographical permutation.

---

## Step 3 : Swap

Swap

- Pivot
- Successor

This makes the permutation just slightly larger.

---

## Step 4 : Reverse the Suffix

The suffix is still in descending order.

To obtain the **smallest possible arrangement**, reverse it.

Descending

```text
6 5 4
```

becomes

```text
4 5 6
```

which is ascending.

---

# 📝 Dry Run

## Input

```text
[1, 2, 3, 6, 5, 4]
```

---

### Step 1 : Find Pivot

Scan from the right.

```text
5 > 4
```

Continue.

```text
6 > 5
```

Continue.

```text
3 < 6
```

Found the pivot.

```text
        ↓
1 2 3 6 5 4
    Pivot
```

Pivot = **3**

---

### Step 2 : Find Successor

Move from the right.

Need the first element greater than **3**.

```text
4 > 3
```

Found.

```text
        ↓     ↓
1 2 3 6 5 4
  Pivot  Successor
```

Successor = **4**

---

### Step 3 : Swap

Swap 3 and 4.

```text
1 2 4 6 5 3
```

---

### Step 4 : Reverse the Suffix

Current suffix:

```text
6 5 3
```

Reverse it.

```text
3 5 6
```

Final answer:

```text
1 2 4 3 5 6
```

This is exactly the **next lexicographical permutation**.

---

# ❗ Special Case

Suppose the array is

```text
3 2 1
```

Scanning from the right,

there is **no pivot**.

This means the entire array is already in descending order,

which is the **largest permutation**.

Therefore,

reverse the entire array.

```text
3 2 1
```

↓

```text
1 2 3
```

---

# ✅ Approach : Two Pointers

### Idea

- Find the rightmost pivot.
- Find the rightmost element greater than the pivot.
- Swap them.
- Reverse the suffix using two pointers.

---

### Time Complexity

```text
O(n)
```

One pass to find the pivot,

one pass to find the successor,

and one pass to reverse.

---

### Space Complexity

```text
O(1)
```

Only constant extra space is used.

---

### Code

```java
class Solution {
    public void nextPermutation(int[] nums) {

        int n=nums.length;
        int pivot=-1;

        // Find pivot
        for(int i=n-1;i>0;i--){
            if(nums[i-1]<nums[i]){
                pivot=i-1;
                break;
            }
        }
        // Already the largest permutation
        if(pivot==-1){
            reverse(0,n-1,nums);
        }
        else{

            // Find successor
            int j=n-1;
            while(nums[j]<=nums[pivot])
                j--;
            // Swap
            int temp=nums[pivot];
            nums[pivot]=nums[j];
            nums[j]=temp;
            
            // Reverse suffix
            reverse(pivot+1,n-1,nums);
        }
    }

    static void reverse(int left,int right,int[] arr){
        while(left<right){
            int temp=arr[left];
            arr[left]=arr[right];
            arr[right]=temp;
            left++;
            right--;
        }
    }
}
```

---

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Two Pointers | O(n) | O(1) |

---

# 🎯 Key Takeaways

- Next Permutation is a classic **Two Pointers + Greedy** problem.
- The suffix after the pivot is always in **descending order**.
- The pivot is the **rightmost element** such that:

```text
nums[i] < nums[i+1]
```

- The successor is the **rightmost element greater than the pivot**.
- Swap the pivot and successor.
- Reverse the suffix to obtain the **smallest possible arrangement**.
- If no pivot exists, the array is already the largest permutation, so simply reverse the whole array.
