## 📖 Problem Statement

Given an `m × n` binary matrix `mat`, return a matrix where each cell contains the **distance to the nearest `0`**.

The distance between two adjacent cells (sharing an edge) is **1**.

---

# 💡 Observation

A naive approach would be:

- For every `1`,
- Run a BFS to find the nearest `0`.

If there are many `1`s, this becomes very expensive.

Instead,

think in reverse.

Rather than searching **from every `1` to a `0`**,

start from **every `0` simultaneously** and spread outwards.

This is a classic **Multi-Source BFS** problem.

---

# 🧠 BFS Thinking

## What does the question ask?

For every cell,

find the **shortest distance to the nearest `0`**.

---

## Why BFS?

BFS always explores nodes **level by level**.

Therefore,

the first time a cell is visited,

it is guaranteed to be reached using the **shortest possible distance**.

---

## Why Multi-Source BFS?

Instead of starting BFS from one source,

we start BFS from **every `0`**.

Initially,

all `0`s are inserted into the queue.

```text
Queue

0   0   0
    0
0       0
```

Each of them expands simultaneously.

Whichever `0` reaches a cell first gives its minimum distance.

---

# ✅ Approach : Multi-Source BFS

### Idea

- Create a distance matrix.
- Initialize every distance as `-1` (unvisited).
- Mark every `0` with distance `0`.
- Push every `0` into the queue.
- Perform BFS.
- Every unvisited neighbour gets

```text
dist[current] + 1
```

---

### Time Complexity

```text
O(m × n)
```

Each cell is visited exactly once.

---

### Space Complexity

```text
O(m × n)
```

Distance matrix +

Queue

---

### Code

```java
class Solution {
    public int[][] updateMatrix(int[][] mat) {

        int m = mat.length;
        int n = mat[0].length;

        int[][] dist = new int[m][n];

        int[][] dirs = {
            {0,-1},   // left
            {-1,0},   // up
            {0,1},    // right
            {1,0}     // down
        };

        // initialize all cells as unvisited
        for(int i=0;i<m;i++)
            Arrays.fill(dist[i],-1);

        // all zero cells have distance 0
        for(int i=0;i<m;i++){
            for(int j=0;j<n;j++){
                if(mat[i][j]==0)
                    dist[i][j]=0;
            }
        }

        Queue<int[]> q=new LinkedList<>();

        // push every zero into the queue
        for(int i=0;i<m;i++){
            for(int j=0;j<n;j++){
                if(dist[i][j]==0)
                    q.offer(new int[]{i,j});
            }
        }

        while(!q.isEmpty()){

            int[] curr=q.poll();

            int r=curr[0];
            int c=curr[1];

            for(int[] d:dirs){

                int nr=r+d[0];
                int nc=c+d[1];

                if(nr>=0 && nr<m &&
                   nc>=0 && nc<n &&
                   dist[nr][nc]==-1){

                    dist[nr][nc]=dist[r][c]+1;
                    q.offer(new int[]{nr,nc});
                }
            }
        }

        return dist;
    }
}
```

# 📊 Complexity

| Approach | Time Complexity | Space Complexity |
|-----------|-----------------|------------------|
| Multi-Source BFS | O(m × n) | O(m × n) |

---

# 🎯 Key Takeaways

- This is a classic **Multi-Source BFS** problem.
- Instead of running BFS from every `1`, start BFS from every `0`.
- Initialize every `0` with distance `0`.
- The first time a cell is visited is its shortest distance.
- Every cell is processed only once, making the solution linear.

---

# 🌊 BFS Expansion

Suppose the matrix is

```text
0 1 1

1 1 1

1 1 0
```

Initially,

```text
Queue

(0,0)
(2,2)
```

Distance matrix

```text
0 -1 -1

-1 -1 -1

-1 -1  0
```

After one BFS level

```text
0 1 -1

1 -1 1

-1 1 0
```

After the next level

```text
0 1 2

1 2 1

2 1 0
```

Every layer of BFS increases the distance by **1**, guaranteeing the shortest distance to the nearest `0`.

---

# 📌 Pattern Recognition

When a problem asks:

- Shortest distance in an **unweighted graph**
- Distance from the **nearest** source
- Minimum number of moves
- Nearest hospital / gate / exit / zero

Think:

```text
Multi-Source BFS
```

instead of running BFS from every starting point.
